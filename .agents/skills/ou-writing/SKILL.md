# OU Writing

확인된 사실과 직접 작성물 기반의 목소리 적용. `little-prince`는 문체가 아닌 가치 판단에만 사용.

## 핵심 원칙

- 현재 요청의 사실, 초안, 목적을 최우선 근거로 사용
- 직접 작성물과 선택한 문장의 역할 분리
- 경험, 관계, 장면, 감정의 임의 생성 금지
- 추상적 감성보다 구체적 관찰과 개인적 의미 우선
- 감탄이나 성찰을 다음 판단 또는 행동으로 연결
- 자연스러운 말투 유지, 의도적인 오탈자 삽입 금지

## 입력 판정

작업 시작 전 다음 항목 확인:

- 글 종류: 편지, 축하 메시지, 개인 소감, 회고, 기술 에세이, 블로그 글, 교정
- 독자와 관계: 친밀도, 존댓말 여부, 공개 범위
- 글의 목적: 감사, 축하, 설득, 기록, 성찰, 설명
- 사용 가능한 사실: 실제 사건, 관찰, 장면, 감정, 다음 행동
- 결과 형식: 짧은 메시지, 완성 원고, 개요, 문장 교정

정보 누락 처리:

- 영향이 작은 정보 누락: 최소 가정 명시 후 진행
- 관계, 사실, 공개 범위 등 중요 정보 누락: 짧고 구체적인 확인

## 작성 흐름

1. 요청의 목적, 독자, 사실, 원하는 길이 추출
2. 글 종류에 맞는 레퍼런스만 로드
3. 핵심 메시지를 한 문장으로 정리
4. 실제 관찰 또는 문제에서 시작하는 구조 선택
5. 초안 작성
6. 사실성, 구체성, 자연스러움, 행동 연결 검토
7. 안티패턴 발견 시 한 번 재작성

## 출력 규칙

- 초안 요청 시 완성 원고 우선 제공
- 설명 요청이 없으면 장황한 작성 해설 생략
- 불확실한 사실은 자연스럽게 제거하거나 명시적 자리표시자로 표시
- 원문 교정 시 고유한 표현과 관계의 온도 보존
- 공개 글에서 사적인 정보의 노출 범위 임의 확대 금지
- 사용자가 요구한 형식과 분량 우선

## 금지 사항

- `little-prince` 문장의 시적 어조를 OU의 실제 문체로 모사
- 없던 추억, 대화, 감정, 성과 생성
- 모든 글을 그리움이나 상실의 정서로 수렴
- 근거 없는 칭찬과 자기계발식 결론 추가
- 기술 글을 AI 찬양이나 도구 목록으로 대체
- 자연스러움을 이유로 맞춤법 오류를 의도적으로 재현
