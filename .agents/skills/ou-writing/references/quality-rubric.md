# 품질 점검표

최종 원고 전 1회 점검. 치명 항목 발견 시 재작성.

## 치명 항목

- [ ] 제공되지 않은 경험, 장면, 관계, 감정, 성과 없음
- [ ] `little-prince`의 문체를 OU의 실제 문체로 사용하지 않음
- [ ] 현재 요청의 독자, 목적, 존댓말 수준과 일치
- [ ] 외부 주장과 OU의 경험 또는 해석을 구분
- [ ] 사적 정보의 공개 범위를 임의로 넓히지 않음
- [ ] 초안 작성 시점·사용자 평가에 맞는 자료 역할 적용
- [ ] 승인된 이전 버전의 확인된 장점 회귀 없음

## OU 목소리

- [ ] 추상적인 평가보다 구체적인 관찰 또는 문제가 있음
- [ ] 감정이 왜 생겼는지 독자가 이해할 근거가 있음
- [ ] 과하게 문학적이거나 기업 홍보 문구처럼 매끈하지 않음
- [ ] 원문의 자연스러운 어휘와 관계의 온도를 보존
- [ ] 모든 문장을 명언이나 결론으로 만들지 않음
- [ ] 감정이 실제 행동 또는 장면에 연결됨
- [ ] 사건을 밖에서 평가하기보다 당시의 내면에서 말하는 느낌
- [ ] 감정을 숨기지 않되 확대·미화·반복 설명하지 않음

## OU 사고 흐름

- [ ] 감탄이나 비판에서 멈추지 않고 자신의 판단이 있음
- [ ] 필요한 경우 자신의 경험, 한계, 기존 가정과 연결
- [ ] 배움이 실제 다음 행동 또는 검증으로 이어짐
- [ ] AI와 도구보다 문제, 선택, 사용자 변화가 중심
- [ ] 비판 대상 전체를 단정하지 않고 이유와 범위를 표시

## 문장 품질

- [ ] 같은 의미의 반복이 의도적임
- [ ] `진심으로`, `참`, `정말`, `많이` 같은 강조어가 가까운 문단에서 불필요하게 반복되지 않음
- [ ] 접속어와 수식어가 생각의 흐름을 방해하지 않음
- [ ] 맞춤법과 띄어쓰기를 교정하되 말투를 평준화하지 않음
- [ ] 한 문단 한 생각과 충분한 여백 유지
- [ ] 요구한 길이와 형식 준수

## 안티패턴 탐지

다음 중 하나라도 불필요하게 나타나면 수정:

- 근거 없는 `분명 잘될 거야`
- 실제 장면 없는 과도한 그리움
- 억지스러운 별, 바다, 계절, 장미 비유
- 모든 경험을 성장 서사로 봉합
- 오래된 미완성 초안의 구조를 실제 목소리로 간주
- 드라이한 말투를 이유로 감정 제거
- 장면이 이미 보여준 의미를 결론 문장으로 반복 설명
- `AI 시대에는`으로 시작하는 일반론
- 독자의 선택보다 화자의 감정을 우선하는 관계 표현
- 정보 나열 뒤 개인 판단이 없는 결론
