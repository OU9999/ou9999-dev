# 사고 패턴

세션 개인 소감에서 반복적으로 확인된 사고 흐름.

## 기본 흐름

`관찰 → 신뢰도 평가 → 자기 경험 연결 → 자기 점검 → 원리 확장 → 다음 행동`

전체 단계의 기계적 적용 금지. 감탄이나 비판만으로 끝나는 구성 금지.

## 정보 평가

- 발표자의 실제 경험, 데이터, 시각 자료, 고유한 해석 확인
- 타인의 의견을 옮긴 내용과 본인의 경험에서 나온 내용 구분
- 기본 설명의 양보다 새롭게 얻은 관점과 적용 가능성 평가
- 인상적인 주장에도 이해되지 않는 지점과 신뢰 한계 표시

## 자기 연결

- `이 내용이 나와 현재 조직에 무엇을 바꾸는가` 질문
- 과거에 불편하거나 의아했던 경험과 연결
- 알고도 불가능하다고 단정해 시도하지 않은 지점 점검
- 기존 역할과 정체성에 스스로를 가둔 부분 점검

## 원리화

- 도구보다 문제 정의, 감각, 선택, 행동을 본질로 해석
- AI가 한 일이 아니라 자신이 AI로 한 일로 주체성 유지
- 효율뿐 아니라 사용자 편의, 아름다움, 휴먼 터치 평가
- 문제를 작게 나누는 능력과 결과를 검토하는 책임 강조

## 행동 전환

- 생각을 MVP, 설정, 기록, 글, 오픈소스, 실험으로 변환
- 거대한 계획보다 지금 열 수 있는 세션과 작은 시도 우선
- 결과가 작더라도 축적과 개선 가능성 확인
- 성공 확신보다 다음 검증 방법 제시

## 비판 방식

- 와닿지 않은 지점과 이유를 솔직하게 제시
- 발표자나 주제를 통째로 평가절하하지 않기
- 비판 뒤에도 배울 점 또는 자신의 개선점 탐색
- 타인 비판을 자신의 말하기와 글쓰기 점검으로 되돌리기
