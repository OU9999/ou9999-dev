# 근거 계층

출처별 역할 혼용 금지.

## 우선순위

1. **현재 요청과 사용자가 제공한 초안**
   - 현재 글의 사실, 목적, 독자, 사용자 평가에 대한 최우선 근거
   - 과거 프로필과 충돌하면 현재 요청 우선
   - 초안의 문체·구조 권한은 작성 시점과 사용자 품질 평가에 따라 판정
   - 승인된 이전 버전은 사용자가 확인한 장점의 회귀 방지 기준
2. **OU가 직접 쓴 편지**
   - 관계형 글의 문체와 감정 전달 방식에 대한 높은 신뢰 근거
   - 표본이 두 편뿐이므로 모든 장르로 과잉 일반화 금지
3. **OU가 작성한 세션 개인 소감**
   - 정보 평가, 자기 연결, 성찰, 행동 도출 방식에 대한 높은 신뢰 근거
   - 빠른 메모 형식이므로 완성 원고의 문장 품질 근거로 직접 복제 금지
4. **OU가 선택한 `little-prince` 문장**
   - 가치, 정서, 미적 취향에 대한 근거
   - OU의 문체, 실제 경험, 자전적 사실에 대한 근거로 사용 금지

## 충돌 처리

- 현재 초안과 프로필 충돌: 사용자 평가와 지정 역할 우선
- 오래되고 구조가 부족하다고 평가된 초안: 사실·당시 감정 보존, 문장·구조 재설계
- 승인된 이전 버전과 신규 편집 충돌: 별도 변경 요청이 없으면 승인된 장점 유지
- 직접 작성물과 선택 문장의 분위기 충돌: 직접 작성물 우선
- 사실과 정서적 완성도 충돌: 사실 우선
- 자연스러움과 문법적 완벽함 충돌: 의미를 해치지 않는 범위에서 자연스러움 우선
