# 글쓰기 모드

글 종류별 필수 구조만 선택. 전체 단계의 기계적 적용 금지.

## 편지·관계 메시지

권장 흐름:

1. 지금 편지를 쓰는 이유와 솔직한 감정
2. 상대에게서 직접 본 구체적인 모습
3. 그 모습이 자신 또는 주변에 준 영향
4. 함께한 작고 개인적인 장면
5. 관계에 대한 속마음
6. 자신이 하려는 행동 또는 약속
7. 상대다운 미래에 대한 응원

- 관찰 가능한 행동에 연결한 칭찬
- 제공되지 않은 장면 생성 금지
- 짧은 축하 메시지: `관찰 → 의미 → 축하와 지지`로 축소

## 세션 개인 소감

권장 흐름:

1. 가장 강하게 남은 주장이나 장면
2. 와닿거나 와닿지 않은 이유
3. 발표의 신뢰도를 높이거나 낮춘 근거
4. 자신의 경험 또는 조직 상황과 연결
5. 자신의 부족함이나 기존 가정 점검
6. 바로 시도할 작은 행동

- 메모 요청: 불릿과 구어체 유지
- 공개 글 요청: 논리적 연결 보강, 솔직한 반응 유지

## 기술 에세이·블로그

권장 흐름:

1. 실제로 겪은 문제, 의문, 장면에서 시작
2. 기술이나 발표 내용을 필요한 만큼만 설명
3. 기존 방식에서 느낀 마찰과 한계 제시
4. 자신의 관점과 판단 기준 제시
5. 작은 실험 또는 적용 경험 연결
6. 무엇이 달라졌고 무엇은 아직 모르는지 구분
7. 다음 행동이나 독자에게 남길 질문으로 마무리

- 기술 설명의 경험담 위장 금지
- 외부 주장과 자신의 해석 구분
- 도구 이름보다 문제와 사용자 변화 중심

## 회고

권장 흐름:

1. 기대했던 것과 실제로 일어난 일
2. 잘된 선택과 놓친 선택
3. 당시에는 보이지 않았던 이유
4. 자신에게 남은 감정과 배움
5. 다음에 바꿀 작은 행동

- 실패의 성급한 교훈화 금지
- 감정과 원인 인정 후 행동으로 이동
- 여러 사건을 하나의 관점 변화로 연결하되 표어처럼 반복 금지
- `장면·행동 → 솔직한 감정 → 개인 판단` 중심의 내면 흐름
- 오래된 미완성 초안: 사실·당시 감정 추출 후 전체 구조 재설계 가능
- 승인된 이전 버전: 가독성, 여백, 문단 흐름의 회귀 방지 기준으로 사용

## 재작성·교정

- 원문에서 사실, 개인 표현, 관계의 온도와 사용자 지정 역할 먼저 표시
- 일반적인 칭찬, 상투적인 연결어, 과장된 결론 축소
- 추상 문장을 가능한 경우 실제 관찰과 영향으로 전환
- 문장만 매끄럽게 만들다가 화자의 솔직함을 제거하지 않기
- 오래된 초안의 약한 구조를 개성으로 간주해 보존하지 않기
- 사용자 승인 요소를 다음 버전의 비교 기준으로 유지
- 큰 구조 변경이 필요하면 수정 이유와 선택지 간략 제시
