# 장면과 논증을 함께 살리는 방법

## 기본 관계

- 장면: 주장의 장식이 아닌 근거
- 질문: 사건을 하나의 글로 묶는 중심
- 개념: 장면을 다시 이해하는 최소한의 기준
- 반론: 화자를 돋보이게 하는 장치가 아닌 주장 범위의 교정
- 결론: 성공 선언이 아닌 현재 확인 가능한 답

장면만 이어 붙인 사건 기록과 개념만 이어 붙인 보고서 사이의 균형 유지.

## 원재료 변환

| 원재료 | 원고에서 가능한 역할 | 금지 |
|---|---|---|
| 사실·장면 | 질문의 출발, 행동의 시험, 전환 장면 | 감정·인과 자동 부여 |
| 사용자 판단 | 동기, 해석, 잠정 답 | 더 멋진 명제로 확대 |
| 반대 해석 | 주장의 한계와 긴장 | 허수아비 반론으로 약화 |
| 불확실성 | 결론의 범위 | 해결된 척 봉합 |
| 보류 재료 | 별도 글 후보 | 길이를 위한 재삽입 |

사용자가 자신의 동기를 알고 있다고 밝힌 경우, 인식론적으로 엄격해 보인다는 이유로 `동기는 분리할 수 없다`는 불확실성 생성 금지.

확인된 감정만 사용. `기쁨보다 먼저 두려웠다`, `안도했지만 불안했다`처럼 원재료에 없는 감정의 대비와 시간 순서 생성 금지.

## 권장 흐름

필요한 구간만 선택:

1. 익숙한 역할이나 설명이 흔들린 실제 사건
2. 처음 붙인 설명과 자꾸 돌아오는 다른 질문
3. 선택적으로 피해온 지점과 자기모순
4. 반대 해석에서 실제로 인정한 영향과 화자가 확정한 선택 동기를 분리
5. 생각을 예전과 다른 행동으로 시험한 사건
6. 행동의 의미가 달라진 거울 장면
7. 외부 결과와 개인 변화를 제한한 현재의 답

시간순 사건 나열보다 질문에 대한 생각의 변화를 우선. 환경, 문화, 성과는 핵심 질문을 시험하는 조건일 때만 유지.

원재료를 많이 보존하는 것이 목표가 아니다. 원문에 있는 반문이라도 이후 장면이 답하지 않고 결말이 회수하지 않으면 경쟁하는 가지다. 특히 `나만 만들 결과`, `더 큰 가능성`, `다른 문제의 해결`처럼 화자의 잠재력을 새 주제로 여는 문장은 현재 질문에 꼭 필요한 근거만 남기고 삭제.

핵심 질문은 초반 실제 장면 뒤에서 분명히 열기. structure의 구체 대상이 `사람 문제, 자기표현, 평가`라면 이를 `어려운 일`로 넓혀 쓰지 않기. 글 전체에서 질문의 주어와 대상을 같은 범위로 유지.

## 장면과 사유의 왕복

1. 관찰 가능한 행동·표정·말 제시
2. 당시 화자의 질문이나 감정 제시
3. 그 장면으로 달라진 판단 제시
4. 다음 선택 또는 남은 의문으로 이동

장면 직후 의미를 모두 해설하지 않기. 독자가 이미 알 수 있는 감정은 한 번 더 이름 붙이지 않기.

## 개념 사용

- 한 글에 핵심 구분 하나 우선
- 추상 이름보다 생활어 우선
- 소개한 구분을 서로 다른 두 지점에서 실제 판단 기준으로 사용
- 화자를 더 용감하거나 옳은 사람으로 만드는 이분법 금지
- 원재료보다 개념이 앞서면 삭제 또는 장면 뒤로 이동
- 개념을 `반례`, `첫 시험`, `처음 질문의 답`, `현재 가능한 범위`라고 해설하지 말고 장면에서 드러내기
- structure 설계어는 작성자의 내부 지도이며 원고 어휘가 아님

## 문단 연결과 호흡

- 한 문단 한 생각
- 직전 문단의 질문에 답하거나 이전 설명의 부족함을 드러내며 시작
- 짧은 단정 뒤 구체적 이유 배치
- 독립 질문 문단 연속 사용 금지
- 같은 단어와 유보 표현의 근거리 반복 축소
- 긴 문단은 생각이 바뀌는 지점에서 분리
- 섹션 끝에서 모든 것을 요약하지 말고 다음 구간이 필요한 이유만 남기기
- 메모의 명사구를 문장으로 옮긴 뒤 조사 호응, 주어·서술어 결합, 자연스러운 연어 재검사
- 같은 어근을 이웃 문장에서 되풀이하거나 장면의 의미를 다음 문단에서 다시 해설하지 않기
- 병렬 항목이 서로 다른 조사를 요구하면 하나의 조사로 묶지 않기
- 쉼표 양쪽이 명사구와 절처럼 다른 문법 단위면 병렬하지 않기. 양쪽을 같은 문형으로 맞추거나 문장을 분리
- 초고 완성 뒤 본문 작성과 분리된 문장별 묵독 교정 패스 수행: 주어·서술어 → 명사·동사 연어 → 조사 병렬 → 지시 대상 → 반복 순서
- `문제가 크다`, `의문이 남다`처럼 실제 생활어에서 목적어와 서술어가 결합하는지 문장을 홀로 떼어 확인. 추상 명사와 범용 동사를 임의로 결합하지 않기
- `이 사실은 반박한다`, `이 장면은 보여준다`처럼 산문의 논증 기능을 해설하지 말고 화자가 그때 알아차린 내용으로 바로 쓰기
- 원인·수단 조사와 서술어의 관계를 확인하고, 감각 동사는 지각 주체와 목적지를 생략해 어색해지지 않았는지 확인
- 인접한 두 문장의 같은 어근은 두 문장을 나란히 놓고 검사. 의미상 필요하지 않으면 한 문장을 다른 구체 동사로 재작성

## 화자의 온도

- 속마음은 가까운 생활어로 직접 제시
- 부끄러움, 두려움, 기쁨을 실제 장면에 연결
- 성과와 장점을 어필하지 않고 행동의 구체성으로 드러내기
- 좋은 선택을 했다는 자기평가보다 당시 의도와 실제 한계 기록
- 확정된 내적 의도는 `그렇게 설명하고 싶었다`가 아니라 `그 의도를 알고 있었다`는 인식으로 보존
- 압박·FOMO 같은 외부 조건의 영향을 인정해도, 사용자가 부정한 `등 떠밀림`이나 주된 원인으로 확대하지 않기. 반론에서 사용자가 받아들인 최소 단위와 거부한 핵심을 먼저 분리
- 드라이함을 냉소나 감정 삭제로 오해하지 않기

## 제한적 결론

최대 세 문단에서 다음 세 층을 구분:

1. 직접 관찰한 외부 장면
2. 단정할 수 없는 인과와 장기 변화
3. 화자에게 실제로 달라진 판단 또는 다음 선택

처음 질문과 대표 장면을 함께 회수. 독자에게 같은 행동을 권하거나 경험을 보편 법칙으로 확장하지 않기.

본문에서 이미 처리한 FOMO, 과거 반례, 개념 구분을 결말에서 다시 나열하지 않기. 결말의 각 문단에 새 역할 하나만 부여하고, 같은 한계를 다른 말로 반복하면 삭제.
