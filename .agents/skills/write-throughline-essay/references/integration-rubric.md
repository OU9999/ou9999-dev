# 통합 품질 점검표

최종 원고 제출 전 순서대로 검사. 치명 항목 하나라도 있으면 한 번 재작성.

## 1. 정직성

- [ ] 제공되지 않은 경험, 감정, 동기, 성과, 타인의 반응 없음
- [ ] 사실, 사용자 판단, 해석, 불확실성 구분
- [ ] 사용자가 확정한 내적 의도를 임의의 불확실성으로 훼손하지 않음
- [ ] 원재료에 없는 감정 대비와 감정의 선후관계 없음
- [ ] 확정된 동기를 서술상의 선호나 바람으로 약화하지 않음
- [ ] 외부 조건의 영향을 행동의 주된 원인·등 떠밀림으로 확대하지 않고, 사용자가 인정한 영향과 확정한 선택 동기를 분리함
- [ ] 화자의 장점을 직접 어필하거나 더 불편한 선택을 한 영웅으로 만들지 않음
- [ ] 승인된 이전 원고의 장면과 정직성 회귀 없음

## 2. 관통 구조

- [ ] 핵심 질문과 현재 가능한 답을 각각 한 문장으로 표현 가능
- [ ] 핵심 질문의 구체 대상이 초반부터 결말까지 상위어로 넓어지지 않음
- [ ] 모든 섹션이 질문을 시작·복잡화·시험·반박·회수
- [ ] 경쟁하는 두 번째 주제와 보류 재료 미혼입
- [ ] 원재료의 반문을 포함해 뒤에서 답하거나 회수하지 않는 질문과 화자의 별도 가능성을 여는 가지 없음
- [ ] 가장 강한 반대 해석의 맞는 부분을 인정
- [ ] 반론 뒤 주장의 범위가 커지지 않고 정확해짐
- [ ] 결말이 도입 질문과 대표 장면을 회수

## 3. 장면과 목소리

- [ ] 관찰이 해석보다 먼저 제시됨
- [ ] 감정이 실제 행동이나 장면에 연결됨
- [ ] 한다체 또는 사용자 지정 말투가 일관됨
- [ ] 생활어와 구체적 동사가 추상명사보다 우세함
- [ ] `반례`, `시험`, `핵심 질문`, `회수`, `범위` 같은 구조 설계어가 산문 밖으로 노출되지 않음
- [ ] 감정을 반복 설명하거나 명언처럼 압축하지 않음
- [ ] 자기계발식 일반론과 독자 훈계 없음

## 4. 가독성

- [ ] 한 문단 한 생각과 충분한 여백
- [ ] 짧은 문장과 긴 설명 문장의 리듬 혼합
- [ ] 질문형·결론형 문장 연속 사용 없음
- [ ] 같은 단어, 같은 유보, 같은 의미의 근거리 반복 없음
- [ ] 앞 문단과 다음 문단 사이에 논리적 또는 감정적 연결 존재
- [ ] 맞춤법·조사·호응·연어에 필수 수정 없음
- [ ] 명사화한 메모 표현, 혼합 비유, 지시 대상이 모호한 대명사 없음
- [ ] 병렬 항목의 조사와 문형이 서로 호응함
- [ ] 쉼표로 병렬한 항목이 모두 같은 문법 단위이며 명사구와 절이 섞이지 않음
- [ ] 이웃한 두 문장에 같은 명사·동사 어근이 불필요하게 세 번 이상 나오지 않음
- [ ] 인접 두 문장에서 같은 어근이 한 번씩만 반복돼도 의도적 강조인지 확인했고, 아니면 다른 구체 동사로 고침
- [ ] 각 문장을 홀로 읽어도 주어·서술어와 명사·동사 연어가 자연스럽고, `지점·부분·방향·장면·이야기` 같은 범용 추상어로 목적어를 대신하지 않음
- [ ] 원인·수단·방향 조사가 서술어와 맞고, 감각·이동 동사의 지각 주체와 목적지가 빠지지 않음
- [ ] `이 사실/장면/이야기는 … 반박한다/보여준다`처럼 글의 논증 기능을 해설하는 문장 없음

## 5. 결말

- [ ] 외부 변화의 인과를 과장하지 않음
- [ ] 발표·도전 한 번으로 장기 변화를 증명하지 않음
- [ ] 남은 두려움이나 비용을 숨기지 않음
- [ ] 현재 확인된 변화만 남김
- [ ] 결말은 세 문단 이하이며 본문에서 처리한 반론을 다시 요약하지 않음

## 판정

- 치명 항목: 하나라도 실패하면 재작성
- 중요 항목: 의미·구조·리듬을 해치면 수정
- 선택 항목: 취향 차이면 원고 유지
