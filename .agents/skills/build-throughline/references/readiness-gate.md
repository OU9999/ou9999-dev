# 작성 준비도 판정

## 필수 조건

다음 조건을 모두 충족한 경우에만 `작성 준비 완료` 판정.

| 조건 | 충족 기준 |
|---|---|
| 핵심 질문 | 사용자가 하나를 선택했고 한 문장으로 표현 가능 |
| 개인적·실무적 긴장 | 왜 이 질문이 화자에게 중요한지 실제 근거 존재 |
| 임시 답 | 원재료가 지지하는 현재의 답 존재 |
| 반대 해석 | 임시 답을 흔드는 반례·대안 설명·한계 중 하나 이상 존재 |
| 구조 기여도 | 모든 본문 구간이 질문을 시작·지지·복잡화·반박·회수 |
| 핵심 연결 | 사건 사이의 인과와 생각 변화가 사용자 답변으로 확인됨 |
| 사실 경계 | 사실, 사용자 판단, 외부 주장, 미확인 해석 구분 |
| 보류 재료 | 핵심에서 벗어난 재료와 제외 이유 기록 |
| 남은 불확실성 | 해결하지 못한 질문을 의도적으로 남길지 결정 |

## 미충족 처리

- 가장 상위 의존성 하나를 `다음 인터뷰`로 선택
- 여러 빈칸을 한 질문에 묶지 않기
- 장면 부족보다 생각의 연결 부족 우선 확인
- 사용자만 답할 수 있는 경험·감정·동기 직접 질문
- 외부 사실 또는 파일로 확인 가능한 내용 직접 조사
- 빈칸을 일반론, 교훈, 매끄러운 연결 문장으로 대체 금지

## 과잉 완결 검사

다음 징후가 있으면 준비 완료 취소 후 재검토:

- 모든 사건이 성공과 성장의 증거로만 사용됨
- 반대 해석이 형식적인 한 문장에 그침
- 결과가 없으면 의미가 없다는 전제
- 화자의 감정을 AI가 대신 명명함
- 핵심 질문이 결론을 이미 포함해 탐색 여지가 없음
- 서로 다른 질문을 연결어로만 묶음
- 글의 길이를 늘리기 위해 사건을 추가함

## 원고 작성 인계 형식

```markdown
## 원고 작성 인계

- 핵심 질문: ...
- 잠정적인 답: ...
- 구조:
  1. <구간 역할> — <사용할 근거>
  2. ...
- 남겨둘 불확실성: ...
- 보류·분리 재료: ...
- 사실 경계:
  - 확인됨: ...
  - 사용자 해석: ...
  - 작성 금지: 확인되지 않은 감정·동기·성과
```

인계 블록은 최종 원고가 아님. 문체 적용, 문단 작성, 제목 결정은 후속 글쓰기 작업에 위임.
