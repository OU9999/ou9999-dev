# Structure 워크시트

## 고정 항목

다음 항목 유지. 글 종류와 원재료에 따라 구간 수와 이름만 조정.

```markdown
# <작업 제목> — 질문 중심 구조

> 상태: 탐색 중 | 작성 준비 완료
> 용도: 최종 원고가 아닌 구조 워크시트

## 원재료

- `<절대 경로 또는 대화>` — 사실·판단·장면 등 사용 범위

## 1. 글의 중심

### 핵심 질문

- <사용자가 선택한 질문>

### 임시 답

- <현재 원재료에서 가능한 잠정적 답>
- [사용자 확인 필요] <확인되지 않은 해석>

### 반대 해석

- <임시 답을 흔들 수 있는 설명 또는 반례>

### 가장 중요한 빈칸

- <사건이나 생각 사이에서 아직 설명되지 않은 연결 하나>

## 2. 구조 지도

### <가변 구간 이름>

#### 역할

- <핵심 질문에서 맡는 역할>

#### 현재 재료

- <확인된 사실·장면·사용자 판단>

#### 직접 정리

- <현재 가장 중요한 질문 하나>

#### 사용자 답변

- <사용자가 직접 작성하는 영역>

## 3. 보류 재료 / 별도 글 후보

| 재료 | 현재 글에서 제외한 이유 | 가능한 별도 질문 |
|---|---|---|
| ... | ... | ... |

## 4. 준비도

| 조건 | 상태 | 근거 또는 남은 빈칸 |
|---|---|---|
| ... | 충족·미충족 | ... |

## 5. 다음 인터뷰

- 현재 질문: <한 개만>
- 질문 이유: <이 답이 열어주는 다음 구조>
```

`원고 작성 인계`는 `작성 준비 완료` 판정 후에만 `readiness-gate.md` 형식으로 추가.

## 가변 구간 설계

사건의 시간순 배열보다 핵심 질문에 대한 사고의 변화를 우선.

### 개인 회고

다음 기능에서 필요한 것만 선택:

- 익숙한 믿음 또는 기대
- 믿음이 흔들린 실제 장면
- 처음의 해석
- 해석과 맞지 않는 경험
- 행동으로 시험한 사건
- 전후를 비교하는 거울 장면
- 현재 가능한 답
- 아직 남은 감정 또는 질문

감정은 장면과 사용자 표현에 연결. 모든 사건을 성장 결과로 완결하지 않기.

### 기술 에세이

다음 기능에서 필요한 것만 선택:

- 실제 문제 또는 관찰
- 기존 설명이나 가정
- 맞지 않았던 증거
- 새 가설 또는 판단 기준
- 실험·구현·사례
- 반례와 대안 설명
- 적용 범위와 한계
- 현재 결론과 다음 검증

기술 이름과 수행 목록보다 문제·판단·검증 관계 우선.

### 혼합형

개인 경험이 기술 주장의 장식이거나 기술 설명이 회고의 배경에 불과하면 비중 축소. 두 재료가 같은 질문의 서로 다른 근거일 때만 유지.

## 핵심 질문 후보 형식

선택 전 대화에서만 다음 형식 사용:

```markdown
### 후보 <번호> — <짧은 이름>

- 핵심 질문: ...
- 긴장: ...
- 주요 근거: ...
- 가장 큰 빈칸: ...
- 보류할 재료: ...
- 판단: 추천 | 가능 | 분리 권장
```

후보를 문구의 차이만 있는 유사 질문으로 채우지 않기. 서로 다른 잠정 답과 글의 범위를 만드는 질문만 제시.

## 갱신 규칙

- `사용자 답변`의 비어 있지 않은 내용 불변
- 새 해석에 `[사용자 확인 필요]` 표시
- 해결된 질문을 `현재 재료` 또는 `임시 답`으로 이동
- 현재 인터뷰 대상 구간 한 곳에만 질문 배치하고 나머지는 `현재 인터뷰 대상 아님` 표시
- `다음 인터뷰`에 질문 한 개만 유지
- 핵심 질문과 맞지 않는 재료를 보류 표로 이동
- 원고처럼 자연스러운 연결 문장 작성 금지
