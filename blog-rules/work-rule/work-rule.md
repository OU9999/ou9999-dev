# Work Rule

작업 진행·검증 규칙. 성공 기준 정의 후 검증될 때까지 반복. 사소한 작업은 판단껏 축소.

## 목표 정의

- 모호한 요청을 검증 가능한 목표로 변환
  - 버그 수정 → 재현 경로 확보 + 수정 후 해소 확인
  - 리팩터링 → 변경 전후 동작 동일 확인
  - 문서·규칙 정리 → 참조 경로와 중복 제거 확인
- 멀티스텝 작업은 간단한 계획과 단계별 검증 항목 명시
- 사용자가 명시하지 않은 운영 작업은 최소 범위로 제한

## 검증 기준

- 기본 코드 변경 → `pnpm lint`
- 빌드·라우팅·콘텐츠 생성 영향 → `pnpm build`
- UI·브라우저 동작 영향 → Playwright 또는 실제 브라우저 확인
