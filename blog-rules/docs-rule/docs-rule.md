# Docs Rule

문서·스킬·규칙 작성 규칙. 지시·목록형 내용은 간결한 명사구 우선.

## 대상

- `AGENTS.md`
- `blog-rules/` 하위 규칙 문서
- `.agents/skills/` 하위 스킬·에이전트 파일
- 루트 Markdown 문서

## 원칙

- 서술형 종결 최소화
- 목록 항목은 한 항목 한 내용
- 같은 개념은 같은 용어로 통일
- 상세 절차는 scope 문서 또는 skill로 이동
- `AGENTS.md`에는 상시 라우팅 규칙만 유지

## 스킬·규칙 작성

- 중복 규칙 작성 금지
- 기존 skill이 담당하는 절차는 skill에 보관
- 새 규칙은 실제 반복되는 실수나 운영 절차만 추가
- 프로젝트 외부 도메인 규칙 복붙 금지

## 교정 예시

| 장황한 표현 | 권장 표현 |
| --- | --- |
| 빌드를 실행합니다. | 빌드 실행 |
| PR을 만들기 전에 확인해야 한다. | PR 생성 전 확인 |
| 릴리즈 배포가 성공했는지 검증한다. | release 배포 성공 검증 |
